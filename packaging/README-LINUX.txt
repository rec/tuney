Tuney for Linux
===============

Version: <version>

How to run Tuney:

1. Extract Tuney-<version>-Linux.tar.gz.
2. Open the extracted Tuney folder.
3. Run the Tuney executable inside that folder.

Tuney needs working audio and MIDI support on your Linux desktop. If Tuney reports
an error, use Help > Show Log Location to find the log file.
