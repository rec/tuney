Tuney for macOS
===============

Version: <version>

This build is unsigned. macOS may warn before running it.

How to run Tuney:

1. Open Tuney-<version>-macOS.zip.
2. Right-click Tuney.app and choose "Open".
3. If macOS asks for confirmation, choose "Open" again.

If Tuney reports an error, use Help > Show Log Location to find the log file.
