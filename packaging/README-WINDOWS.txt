Tuney for Windows
=================

This build is unsigned. Windows or antivirus software may warn before running it.

How to run Tuney:

1. Right-click Tuney-<version>-Windows.zip and choose "Extract All...".
2. Open the extracted Tuney folder.
3. Double-click Tuney.exe.

Do not move Tuney.exe out of the folder. It needs the files next to it.

If antivirus software quarantines Tuney, restore it only if you trust that you got
the file from the official Tuney GitHub release. Some antivirus tools flag unsigned
PyInstaller applications even when they are harmless.

For repeated testing, create a dedicated folder such as:

    C:\Users\<name>\Apps\Tuney

Then add that folder as an allowed or excluded folder in your antivirus software.
