# tuney

Turn typing or text into musical notes.

* Highly configurable
  * Note mappings
  * Microtonal scales
  * Timings

* Multiple forms of output
  * Built-in synthesizer
  * MIDI send
  * Standard MIDI File (.smf)
  * Text
  * JSON

* Two forms of input
  * Text files, with customizable timing
  * Live typing
  * (MIDI to text - not yet implemented)
