usage: tuney [-h] [OPTIONS]

 positional arguments                                                                                                   
 ---------------------------------------------------------------------------------------------------------------------- 
  [{None}|PATH]                                                                                                         
        Load configs from a JSON or toml file (default: None)                                                           
                                                                                                                        
 options                                                                                                                
 ---------------------------------------------------------------------------------------------------------------------- 
  -h, --help                                                                                                            
        show this help message and exit                                                                                 
  --text TEXT                                                                                                           
        Text to start the program with (optional)                                                                       
  --max-gap FLOAT                                                                                                       
        Maximum silent gap to keep in recordings, in seconds (default: 4.0)                                             
  --hover-time FLOAT                                                                                                    
        Time to hover over a widget before showing help, in seconds (default: 1.0)                                      
  --cli, --no-cli                                                                                                       
        Run without opening the graphical interface (default: False)                                                    
  --silent, --no-silent                                                                                                 
        Disable synthesized audio output (default: False)                                                               
  --output {None}|PATH                                                                                                  
        Audio file to write while playing text (default: None)                                                          
  --run-in-background, --no-run-in-background                                                                           
        If True, listen to the keyboard even when other applications are in front (default: False)                      
                                                                                                                        
 mapper options                                                                                                         
 ---------------------------------------------------------------------------------------------------------------------- 
  Map letters to notes                                                                                                  
  ----------------------------------------------------------------------------------------------------------------------
  --mapper.alphabet {None}|STR                                                                                          
        Characters mapped to note numbers, or the default alphabet if empty (default: None)                             
  --mapper.length INT                                                                                                   
        Number of note numbers to cycle through; zero uses the full alphabet (default: 0)                               
  --mapper.case-sensitive, --mapper.no-case-sensitive                                                                   
        Treat uppercase and lowercase characters as distinct (default: True)                                            
  --mapper.invert, --mapper.no-invert                                                                                   
        Reverse the order of mapped note numbers (default: False)                                                       
  --mapper.offset INT                                                                                                   
        Offset added to mapped note numbers (default: 0)                                                                
                                                                                                                        
 player options                                                                                                         
 ---------------------------------------------------------------------------------------------------------------------- 
  How to play back audio                                                                                                
  ----------------------------------------------------------------------------------------------------------------------
  --player.gain FLOAT                                                                                                   
        Audio output gain (default: 1.0)                                                                                
  --player.note-offset INT                                                                                              
        Offset added to generated note numbers before tuning (default: 44)                                              
  --player.polyphonic-headroom FLOAT                                                                                    
        Divisor applied to mixed voices to provide polyphonic headroom (default: 4)                                     
  --player.max-polyphony INT                                                                                            
        Maximum number of notes that can play simultaneously (default: 32)                                              
  --player.minimum-note-time FLOAT                                                                                      
        Minimum duration of each synthesized note, in seconds (default: 0.5)                                            
                                                                                                                        
 player.device options                                                                                                  
 ---------------------------------------------------------------------------------------------------------------------- 
  --player.device.samplerate {None}|INT                                                                                 
        Audio output sample rate, in frames per second (default: None)                                                  
  --player.device.device {None}|INT|STR                                                                                 
        Audio output device name or index (default: None)                                                               
  --player.device.dtype {None,int8,uint8,int32,int16,float32}                                                           
        Sample data type sent to the audio output device (default: None)                                                
                                                                                                                        
 player.oscillator options                                                                                              
 ---------------------------------------------------------------------------------------------------------------------- 
  --player.oscillator.waveform {sine,triangle}                                                                          
        Waveform used to synthesize notes (default: triangle)                                                           
  --player.oscillator.period FLOAT                                                                                      
        Number of waveform cycles per note period (default: 1.0)                                                        
  --player.oscillator.duty-cycle FLOAT                                                                                  
        Fraction of each waveform cycle before its falling edge (default: 0.5)                                          
                                                                                                                        
 player.scale options                                                                                                   
 ---------------------------------------------------------------------------------------------------------------------- 
  --player.scale.alphabet STR                                                                                           
        The base alphabet (default: ABCDEFGHIJKLMNOPQRSTUVWXYZ)                                                         
  --player.scale.root STR                                                                                               
        The root note to start scales with (default: C)                                                                 
  --player.scale.begin STR                                                                                              
        The first note from the alphabet: TODO: validate begin <= base <= end (default: A)                              
  --player.scale.end STR                                                                                                
        The Last note from the alphabet (default: G)                                                                    
  --player.scale.notes {None}|STR                                                                                       
        If `notes` is set, once the scale is generated, only the notes in                                               
        `notes` are actually used in the list.                                                                          
                                                                                                                        
        For example, notes='CDEFGAB' would correspond to only the white notes on the piano. (default: None)             
  --player.scale.intervals [INT [INT ...]]                                                                              
        The intervals between notes. Can also be entered as a string: "2212221" (default: 2 2 1 2 2 2 1)                
  --player.scale.offset INT                                                                                             
        Offset all note numbers by this (default: 0)                                                                    
                                                                                                                        
 player.scale.tuning options                                                                                            
 ---------------------------------------------------------------------------------------------------------------------- 
  The Tuning for this Scale                                                                                             
  ----------------------------------------------------------------------------------------------------------------------
  --player.scale.tuning.detune FLOAT                                                                                    
        Detune everything, in cents of an octave division (default: 0)                                                  
  --player.scale.tuning.limit INT                                                                                       
        If limit is greater than zero, use rounded N-limit just intonation (default: 0)                                 
  --player.scale.tuning.notes-per-octave INT                                                                            
        Number of divisions of an octave (default: 12)                                                                  
  --player.scale.tuning.octave-ratio FLOAT                                                                              
        Frequency change between octaves. For the default "power" pitch_to_frequency the change is a ratio, so if it's  
        2, each octave is twice the frequency of the last; for "linear", it's a difference, so if it's 100, each octave 
        would be                                                                                                        
        100Hz greater in frequency than the previous. (default: 2)                                                      
  --player.scale.tuning.root-frequency FLOAT                                                                            
        The frequency of the reference `root_note` (default: 440)                                                       
  --player.scale.tuning.root-note INT                                                                                   
        MIDI note 69 is A440, for non-Yamaha units (default: 69)                                                        
  --player.scale.tuning.table {[FLOAT [FLOAT ...]]}|{[INT FLOAT [INT FLOAT ...]]}                                       
        A table, either a Sequence or a dict, mapping note number to frequency. (default: )                             
  --player.scale.tuning.table-blend, --player.scale.tuning.no-table-blend                                               
        If table_blend is True, then notes that aren't found in the table are then looked up with the default algorithm.
        (default: True)                                                                                                 
                                                                                                                        
 player.scale.tuning.pitch-to-frequency options                                                                         
 ---------------------------------------------------------------------------------------------------------------------- 
  The rule for converting a pitch to a frequency                                                                        
  ----------------------------------------------------------------------------------------------------------------------
  --player.scale.tuning.pitch-to-frequency.function {power,linear}                                                      
        The base rule for converting a pitch to a frequency (default: power)

 text-timings options                                                                                                   
 ---------------------------------------------------------------------------------------------------------------------- 
  Timings for playing back texts                                                                                        
  ----------------------------------------------------------------------------------------------------------------------
  --text-timings.space FLOAT                                                                                            
        Base duration for a space, in milliseconds (default: 100)                                                       
  --text-timings.period FLOAT                                                                                           
        Base duration for a period, in milliseconds (default: 300)                                                      
  --text-timings.comma FLOAT                                                                                            
        Base duration for a comma, in milliseconds (default: 200)                                                       
  --text-timings.colon FLOAT                                                                                            
        Base duration for a colon, in milliseconds (default: 400)                                                       
  --text-timings.semicolon FLOAT                                                                                        
        Base duration for a semicolon, in milliseconds (default: 400)                                                   
  --text-timings.blank-line FLOAT                                                                                       
        Base duration for a blank line, in milliseconds (default: 1000)                                                 
  --text-timings.overlap FLOAT                                                                                          
        Time that consecutive characters overlap, in milliseconds (default: 20)                                         
  --text-timings.seed {None}|INT                                                                                        
        Seed for randomized character timings, or a random seed if empty (default: None)                                
  --text-timings.alpha-only, --text-timings.no-alpha-only                                                               
        Ignore characters without an explicit timing unless they are alphabetic (default: True)                         
  --text-timings.strip-accents, --text-timings.no-strip-accents                                                         
        Remove accents before generating character events (default: True)                                               
  --text-timings.scale FLOAT                                                                                            
        Multiplier applied to all generated timing values (default: 3.0)                                                
  --text-timings.other [STR FLOAT [STR FLOAT ...]]                                                                      
        Additional per-character base durations, in milliseconds (default: )                                            
  --text-timings.timings {None}|{[FLOAT [FLOAT ...]]}                                                                   
        Possible durations for alphabetic characters, in milliseconds (default: None)
