# New feature ideas, 14 July

Aside from MIDI out, these are feature directions that fit Tuney well.

## Render and export improvements

- Export MIDI files, even if live MIDI is limited for microtonal use.
- Export stems: dry audio, per-character or note groups, or separate waveform layers.
- Batch render multiple text files or presets.

## Scala browser polish

- Search or filter by name or description.
- Favorites and recently used Scala scales.
- Preview or audition button for the selected scale.
- Categories or tags for common tuning families.

## Preset system expansion

- Section presets for mapper, sound, timing, tuning, and scale.
- Recently used presets.
- Preset notes and descriptions.
- Import and export preset bundles.

## Composition controls

- Humanize timing and velocity or gain separately.
- Repeat or loop selected text ranges.
- Transform text before mapping: reverse, shuffle words, remove punctuation, case modes.
- Per-character duration and gain editing.

## Performance tools

- Live keyboard sustain or hold mode.
- Panic or all-notes-off button.
- Record takes with timestamps.
- Metronome or count-in for replay.

## Audio engine features

- Envelope controls: attack, decay, sustain, release.
- Low-pass and high-pass filters.
- Chorus, delay, and reverb.
- Per-note stereo panning.

## Microtonal usefulness

- Show the active note frequency and ratio or cents offset.
- Tuning comparison view.
- Detect impossible or invalid tuning setups earlier.
- Export `.scl` from computed tunings.

## Usability

- Built-in example texts.
- Reset-this-section commands.
- Search settings by name.
- Better onboarding and first-launch help.

## Top candidates

The strongest near-term candidates are:

- Better Scala search and favorites.
- ADSR envelope controls.
- Improved audio export and batch rendering.
